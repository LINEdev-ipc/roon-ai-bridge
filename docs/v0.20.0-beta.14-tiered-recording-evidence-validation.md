# v0.20.0 Beta 14 Tiered Recording Evidence Validation

## Why this beta exists

The deployed Beta 13 gate improved exact-performance precision but reduced
coverage and increased latency:

| Case | Beta 12 | Beta 13 | Beta 13 elapsed |
| --- | ---: | ---: | ---: |
| P06 remixes | 65/100 | 30/100 | 478.9 s |
| P07 live | 71/100 | 34/100 | 444.9 s |
| P08 acoustic/covers | 65/100 | 38/100 | 421.5 s |

Roon often returned the exact playable title and requested performer while
omitting album, duration and album navigation. Beta 13 treated that missing
edition metadata as a failed recording identity even when MusicBrainz had
already established the canonical recording.

## Corrective design

MusicBrainz remains the source of truth. Exact recording families still require
the selected MusicBrainz recording to occur on the requested release. Beta 14:

- treats harmless release suffixes such as `(Live)`, a remaster marker or an
  edition marker as the same release title;
- keeps the release requirement through every core-title fallback;
- includes the release in cover searches when a release match is required;
- accepts acoustic performances that MusicBrainz describes as both unplugged
  and live;
- uses the `v9` recording-resolution cache namespace so failed Beta 13
  decisions cannot be reused.

Roon remains only the playback binding. Evidence is now tiered:

1. A shared ISRC or compatible observed album is decisive.
2. An exact published version title plus compatible performer binds a named
   remix, edit or dub without requiring Roon album metadata.
3. Exact title plus the requested covering performer binds a cover.
4. A live or acoustic title requires a compatible album, canonical duration,
   or a Roon suffix carrying release-specific venue/year evidence.
5. Otherwise the candidate remains unresolved for manual repair.

Album recovery now searches with the requested performer before Roon's flat
credit list. This prevents composers and remix contributors from displacing
the actual artist in album and artwork searches.

Strong bindings skip Roon release navigation but still store the canonical
MusicBrainz profile and the sparse playable Roon observation. Ordinary studio
recordings retain their existing fast path.

## Automated evidence

Focused regressions cover:

- Depeche Mode `Home (Air "Around the Golf" Remix)` with no Roon album or
  duration;
- Cat Power `Wild Is the Wind` as a cover with no Roon album;
- Nina Simone `The Other Woman`, accepting only a `Town Hall` suffix while
  rejecting New York 1964;
- the same Nina Simone title with a generic `Live` suffix, which must still
  verify its album;
- Shakira and The Corrs unplugged recordings across Roon live and alternate
  classifications;
- `MTV Unplugged` versus `MTV Unplugged (Live)`;
- preservation of a required release through MusicBrainz core-title fallback;
- release search using the requested performer instead of polluted Roon
  credits.
