# v0.20.0 Beta 7 Playlist Reconstruction Validation

## Objective

Beta 7 makes MusicBrainz the durable identity and metadata source for playlist
tracks. Roon remains responsible for locating a currently playable item and
for the artwork observed on that playable edition.

## Expected behavior

- A canonical recording stores the MusicBrainz title, complete artist credit,
  release group, duration, ISRC, dates, work credits and genres.
- Country-specific editions of the same recording may bind to Roon. Live,
  remix, acoustic and other recording families remain distinct.
- A transient missing or ambiguous playback search does not overwrite a valid
  canonical identity or last durable binding.
- Exact retries of the same playlist-build batch return the previous result
  without consuming a round or repeating provider searches.
- Three genuine replenishment rounds are available. A playlist below
  `desired_count` is never saved.
- `roon_rebuild_playlist` migrates old playlists in place and preserves songs,
  order, cover, description, manual selections and user metadata.
- Existing exact MusicBrainz identities are reused without another catalog
  lookup.
- The portal shows compact identity, publication and credit cards. Artist and
  album names open Roon searches; recording, release group, release and work
  references open MusicBrainz.

## Automated validation

Run:

```powershell
pnpm run test
pnpm run build
```

The suite covers idempotent playlist batches, refusal to persist incomplete
lists, canonical metadata overlay, equivalent-edition playback, durable state
after ambiguous playback, reconstruction of legacy identity and preservation
of exact/manual associations.

## Deployment validation

After an explicitly requested beta deployment:

1. Confirm the deployed commit and both reported versions are
   `0.20.0-beta.7`.
2. Confirm MCP `tools/list` contains `roon_rebuild_playlist` and does not
   contain `roon_resolve_playlist` or `roon_refresh_playlist_metadata`.
3. Refresh the ChatGPT app and start a new conversation so tool metadata is
   reloaded.
4. Rebuild an existing playlist with `scope:"all"` and verify its order,
   cover, description and user data did not change.
5. Open songs such as `Hours`, `Halving The Compass` and `Avril 14th`; verify
   canonical artist, album and duration are present and the links work.
6. Play the rebuilt playlist in Despacho. Equivalent Roon editions should play
   without becoming ambiguous, while genuinely different versions should be
   reported and should not alter the stored identity.
